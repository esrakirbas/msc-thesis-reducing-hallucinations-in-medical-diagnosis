# medical-synthetic-prototype-data
## Dataset

This prototype uses a modified version of synthetic patient data downloaded from the official Synthea Downloads page provided by The MITRE Corporation.
### Source : https://synthea.mitre.org/downloads 

The original data was generated by Synthea and does not contain records derived from real patients. For this prototype, some unnecessary columns were removed, and the synthetic first and last names were replaced with artificial identifiers such as PATN001 and PATS001.

Columns that were not relevant to the scope of this work, 
- such as address and geographic information in patient records, 
- administrative and payment related fields in encounter and medication records, 
- cost related fields were removed from the procedure records

were removed from the dataset.

The original synthetic patient IDs were retained to preserve the relationships between records in different CSV files.
